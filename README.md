# WALI — Your Smart World

A mobile-first, multilingual progressive web app concept combining Kurdish culture, creativity and useful digital tools.

## Preview

Open the GitHub Pages deployment after enabling Pages for the repository, or serve this folder with any static web server.

## Included in this first prototype

- Responsive dark-and-gold interface
- Persian, Kurmanji Kurdish and English language switching
- Local idea notebook (saved in the browser)
- PWA manifest and basic offline cache

## Run locally

Because this is a static app, no build step is required. Serve the repository root with a static HTTP server. Service-worker features require HTTPS or localhost.

## Roadmap

1. Confirm product direction and feature priorities.
2. Add real AI, translation and community services only after choosing providers and privacy rules.
3. Add app icons, accessibility checks and deployment automation.

**Note:** AI assistant, translation API, news and social/community features are design concepts in this prototype, not connected services yet.
